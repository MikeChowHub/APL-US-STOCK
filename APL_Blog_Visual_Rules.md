# APL Blog Visual Rules

## Purpose

Every APL Blog Post must generate a distinct visual concept from the article itself.

The cover and SEO image must not reuse a generic chart background.

## Required Creative Flow

Article content
→ Visual evolution
→ Single visual metaphor
→ Cover image
→ SEO image

## Rules

- Extract the article's core market thesis before designing the image.
- Use one primary visual metaphor per article.
- Daily visuals must have different symbolic elements and background structure.
- The visual metaphor should explain the market story, not merely decorate it.
- APL Deep-Scan brand style must remain consistent:
  - Deep ocean environment
  - Radar / sonar logic
  - APL Cyan
  - Dark navy background
  - Clean financial research layout
- Text must be readable and publication-ready.
- Cover size: 1080 × 1350.
- SEO image size: 1280 × 720.
