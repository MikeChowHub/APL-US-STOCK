# 深海追探｜文章模板

用途：生成不同公司的深度專題文章。永久規則見 `KnowledgeBase/Rules/深海追探_專題文章規則.md`；本模板只定義格式。

使用方式：替換佔位內容，移除所有作者提示。標題依公司實際問題改寫，不向讀者展示敘事框架。核實資料不足時明示，不虛構填空。

完整交付包含本文、完整 HTML 原始碼 TXT、完整財務比較圖、1080 x 1350 Cover、橫向 SEO 圖及同批備案，無須使用者另外提出。圖片遵守 `KnowledgeBase/Rules/APL_Deep_Dive_Cover_SEO_Brand_Rules_v1.md`；主標題效果與配色須在兩圖間一致。

保存格式：本文為 `outputs/DeepDive/{股票代號}/{日期}/{版本}/article.md`，同目錄另存 `article-html-source-{版本}.txt` 及 `record.md`；圖片為 `Assets/DeepDive/{股票代號}/{日期}/{版本}/cover.png`、`seo.png` 及 `financial-comparison-{版本}.png`。既有同名批次不得覆蓋。

最終回覆依序列出五個絕對路徑連結：閱讀完整文章、完整文章 HTML 原始碼 TXT、財務比較圖：完整 {實際項數} 項指標、封面、SEO／分享圖。另展示封面與 SEO 圖預覽；不得只交正文而遺漏配套檔案。

備案 `record.md` 格式（不插入文章敘事正文）：

| 欄位 | 內容 |
|---|---|
| 批次 | {股票代號／研究日期／版本} |
| 文章標題 | 美股深海追探：{股票代號} |
| 研究及行情基準 | {研究日期／行情日期／財務期間} |
| 狀態 | {預覽／待確認／已確認；不得虛構審核或發布狀態} |
| 文章 | {專案相對路徑} |
| HTML 原始碼 TXT | {專案相對路徑；完整文章及 SEO 設定；圖片網址是否仍需上傳替換} |
| 財務比較圖 | {專案相對路徑；實際尺寸；完整指標項數；替代文字} |
| SEO 文字 | {URL slug／Page title，不超過 60 字元／Page description；與文章及 HTML 一致} |
| Cover | {專案相對路徑；1080 x 1350；替代文字} |
| SEO | {專案相對路徑；實際橫向尺寸；替代文字} |
| Logo | Assets/Brand/APL_Deep_Scan_Brand_Logo_Renderer_Clean.png |
| 規則 | {文章、圖片規則的路徑及版本／修訂日期} |
| 配圖一致性 | {同公司、同主題、同配色、同主標題漸變；如未完成須明示} |
| 前一版本 | {如有，列出舊批次路徑；不覆蓋} |
