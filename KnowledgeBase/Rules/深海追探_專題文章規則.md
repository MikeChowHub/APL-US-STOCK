# 深海追探｜專題文章規則

版本：1.1（2026-09-16 更新交付規格）

建立日期：2026-09-08
類別：Rules，永久規則來源

## 定位與適用關係

品牌：**美股深海雷達**。公司專題系列：**深海追探**。

文章標題格式：`美股深海追探：{股票代號}`。

母品牌「美股深海雷達」由正式 Logo 及品牌識別呈現，不在文章標題內重複加入。

本文件規範選定公司後的深入研究文章，不是每兩日的「深海追蹤報告」。後者負責新聞及內部上榜篩選，前者把候選公司寫成易讀、具證據的完整專題。

本文件與 `APL_US_Stock_Business_Inflection_Research_Rules.md` 配合使用；專題文體、指標呈現及排除項目以本文件為準，新聞核實與研究誠信要求仍沿用既有規則。不修改評分、排名、生產流程或排程。

## 文體與讀者

- 全文使用繁體中文書面語，不使用粵語口語。
- 對象是完全不了解公司的讀者；先讓讀者理解生意，再閱讀財務。
- 用客戶的具體問題自然開場，形成敘事主線，而不是逐項問答或研究清單。
- 不向讀者宣布正在講故事。禁止使用「故事開始」「故事由……開始」「故事的轉折」「故事的結局」等敘事框架標題。
- 避免「想像一下」「以下回答五個問題」等教學式指令。
- 小標題直接描述實際問題或判斷，隨公司改寫；不得機械複製 TXG 的腫瘤情境。
- 技術及產品名稱首次出現時簡短解釋實際用途，不堆疊名詞或宣傳形容詞。
- 真實案例附來源；假設案例自然註明為解說情境而非已公布訂單，不能為吸引力虛構事實。

## 必須融入文章的五項商業解說

1. 用一個具體客戶情境說明產品或服務、購買過程與收費方式。
2. 誰付款：辨別採購方、支付方及最終消費者。
3. 誰操作或使用：寫明實際使用者，不與付款者混淆。
4. 解決甚麼問題：說明客戶為何需要產品，及現有替代選擇。
5. 需求增加如何形成收入：交代付費數量、價格、收入模式及必要條件。

五項是研究骨架，不作為五條公開問答。必須自然融入段落；簡明說透，不重複鋪陳。

## 固定推進次序

1. 具體問題與客戶情境：介紹產品、付款者、使用者及收入來源。
2. 需求或營運轉變：新事件為何重要，如何可能改變既有生意。
3. 競爭格局：細分市場主要對手、領先依據、替代產品及客戶選擇理由。
4. 財務真相：需求是否已反映收入，增長質素及盈利或虧損原因。
5. 統一同業指標表與估值解讀：判斷相對偏貴或偏便宜，說明合理性與限制。
6. 風險與追蹤：哪些證據支持或推翻論點，以明確研究判斷收結。

以上是作者的內部次序，不直接用作制式六題問卷。段落可自然銜接，但不能省略競爭與價格判斷。

## 財務與估值呈現

所有保留指標放在**同一張完整財務比較圖**，不分「一般／正常指標」及「核心指標」兩張圖。

每個名稱後加括號，以白話解釋如何閱讀；不籠統寫成越高越好或越低越便宜。

保留指標：市值、企業價值 EV、收入、收入增長率、毛利、毛利率、營業利潤率、淨利潤率、EPS、現金、負債或淨現金／淨負債、P/E、P/S、P/B，以及下列必備指標。不得因資料難找而默默刪除；未能可靠取得時註明待核實。

**三項必備：收入收益率、毛利率、毛利收益率。** 毛利率只出現一次。「市值／毛利倍數」依使用者最新要求移除，不再列入表格或作為正文估值主軸。

使用者明確排除：**EV／收入、EV／EBITDA、經營現金流、自由現金流**。不得重新加入指標表，也不自行換成相近現金流指標補回。必要的資金風險可用正文簡述。

公式以簡短表註呈現：

- 收入收益率＝年收入÷市值×100%。
- 毛利率＝年毛利÷年收入×100%。
- 毛利收益率＝年收入×毛利率÷市值×100%，計算時毛利率使用小數。

總額除以總市值，不以公司收入除每股股價。收入收益率與 P/S 互為倒數，不當成獨立證據。毛利收益率不是投資回報。正文以保留指標解釋估值差異，不重新加入已移除的毛利倍數。

## 年度成本與費用

同一張比較表必須加入 TTM 直接成本、TTM 營運費用，以及 TTM 營運成本與費用合計。與收入採相同年度或近十二個月期間，不把單季費用當作年度數字。

- 直接成本：產生收入所需的產品、檢測或服務成本。
- 營運費用：不含上述直接成本的研發、銷售及管理等費用；有可靠分項時在同表拆列，避免重複加總。
- 營運成本與費用合計＝直接成本＋營運費用，用於說明年度收入能否覆蓋營運支出。
- 不同公司可能將直接成本包含在名為「Total operating expenses」的總額中，必須依實際內容重分類，不可再加一次直接成本。
- 出售業務收益等非費用項目不得抵減後冒充日常成本；如需還原費用，列明調整與來源，不稱為已剔除所有一次性項目的核心支出。
- 明確說明年度成本費用是會計口徑，不等於實際付出現金，也不包括所有收購、資本支出或還本。不可稱為「全年現金花費」。
- 淨現金是期末存量，年度成本費用是期間流量；不能互相替代，亦不得以淨現金除費用合計推算資金續航。

## 數據與盈利解釋

- 明列報告日期、行情日期、財務期間、幣別及單位。
- 同業採同口徑比較；原報表與供應商標準化毛利不得混用而不交代。
- 不把集團收入當作競爭部門收入；無獨立市佔資料，不宣稱某公司全面排名第一。
- 虧損時 P/E 不適用；毛利或淨資產非正值時，相應估值倍數須註明解讀限制。
- 把正常營運與一次性和解、處分、補助、退款及追溯收入分開。
- 不只寫「營運費用多少、最後虧損多少」。必須解釋：收入－直接成本＝毛利；毛利－營運費用＝營運損益；再經其他損益及稅項得到淨損益。
- 說明費用用在哪裡，以及相對毛利為何過高。重大增減應解釋原因，無分項證據時不可猜測。
- 可加簡短收支橋接表；它是損益說明，不是第二張估值指標表。
- 預覽的未核實數字明確標示；正式稿不得沿用「待對帳」底稿當作已核實結論。
- 其他股票必須重新研究，不沿用 TXG 的數據、估值日期、對手或商業假設。

## 必須作出的估值判斷

表後用文字回答：相對所選同業偏貴、偏便宜，還是證據不足；差距有多少；哪些增長、盈利、負債及業務差異可能解釋差距。

相對偏貴不等於已證實高估，相對偏便宜不等於值得買。不能只套用同業平均倍數給出合理股價。

可用清楚標示的敏感度假設說明價格要求多少收入或毛利增長，不把假設倍數當目標價。結尾列出能驗證或推翻估值論點的具體營運證據。

## 文件管理與使用

配套格式：`KnowledgeBase/Templates/深海追探_文章模板.md`。

TXG 文章只供敘事參考，不是規則或未來數據來源；執行本流程不依賴 `outputs/深海追探.md` 存在。新文章保存到 Outputs 類別，使用股票代號及日期區分，遇同名不覆蓋。

使用者說「按深海追探格式研究 {股票}」時，先確認公司與代號，依本規則及模板研究並撰寫。不需再次詢問已確定的文體與指標偏好。

## 文章與配圖一體交付（2026-09-15 起）

- 使用者要求「一篇／一份深海追探」時，預設交付完整文章 Markdown、完整文章 HTML 原始碼 TXT、財務比較圖、Cover 封面、SEO 搜尋／分享圖片及同批備案記錄；不需另外要求配套檔案。語音轉寫「深海追嘆」等，如上下文清楚，按本系列處理。
- 圖片永久規則來源為 `KnowledgeBase/Rules/APL_Deep_Dive_Cover_SEO_Brand_Rules_v1.md`。文章模板同時規範配圖與備案格式。
- Cover 固定為 1080 x 1350（4:5）。SEO 為另行構圖的橫向圖片，記錄實際尺寸，不以裁切封面取代，也不將非標準尺寸誤稱為標準尺寸。
- 兩圖共用深海藍、青藍、銀白配色，以及上銀白、下冰藍的主標題漸變、細緻紋理和淡青藍光暈。不得在 SEO 另用純白主標題或金色裝飾。
- 正式透明 PNG Logo 以原比例、小尺寸置於左上角，直接透明疊合連續背景，不加底板、不搶主題，不使用 AI 重畫品牌。
- 圖片須反映當篇公司及文章主題，不複製 CXAI 場景套用於無關行業；舊案例及輸出不是跨電腦執行依賴。
- 每批以股票代號、研究日期及版本識別。文章与備案存放 `outputs/DeepDive/{股票代號}/{日期}/{版本}/`；兩張圖片存放 `Assets/DeepDive/{股票代號}/{日期}/{版本}/`。文章連結兩圖，備案記錄所有專案相對路徑及適用規則版本。
- 同批保存 `article.md`、`article-html-source-{版本}.txt`、`record.md` 與對應的 `financial-comparison-{版本}.png`、`cover.png`、`seo.png`；缺少任一項時明確標示未完成，不將只有聊天正文或單張圖視為完整交付。
- 圖片替代文字、用途、尺寸與狀態記錄於備案；回覆同時展示文章連結及兩圖預覽。
- 修改另存新版本，更新新批次的對應關係，不覆蓋舊文章、圖像或已發布記錄。
- 本處「備案」指專題文章與素材同批留存，不代表執行每日 Production / Archive V2，亦不自行宣稱正式審核通過或發布完成。未經要求不啟動 Git 操作、每日生產審核或發布流程。

## 配套內容與回覆格式（2026-09-16 起）

- HTML 原始碼 TXT 包含完整文章、可用的 HTML 標籤、來源連結、財務文字表及圖片引用，不是摘要或經 Markdown 跳脫的 HTML；不得把 Markdown 連結語法放進 `href`。尚未上傳的本地圖片須說明發布時需要替換網址，不假稱已上線。
- 財務比較圖呈現全部指標、括號解釋、公司、數值、期間、單位、來源與重要口徑限制；不得為排版刪除成本等指標。文章已有完整清晰的財務比較圖時，不再重複加入同一份 Markdown／HTML 文字表；來源、公式、口徑限制及估值分析仍須保留為可閱讀文字。LDOS 案例為 23 項，其他公司按實際完整項數標示，不虛報 23 項。
- 完整文章與 HTML 文末均加入 `SEO and Sharing`：`URL slug` 為 `/deep-exploration-{股票代號}`、`Page title` 不超過 60 字元、`Page description` 為準確的繁體中文摘要。HTML 的頁面標題及描述設定與此一致，備案同步記錄。
- 最終回覆集中依序提供五項可點擊的絕對路徑連結：「閱讀完整文章」、「完整文章 HTML 原始碼 TXT」、「財務比較圖：完整 {實際項數} 項指標」、「封面」、「SEO／分享圖」。封面及 SEO 圖同時提供預覽，備案一併留存，不要求使用者另行追問檔案。
