# Changelog

本專案依 Semantic Versioning 管理 repository product release。個別 workflow、schema、contract、component 與 design-system 文件可維持各自版本，並不改變 product version。

## [1.0.0] - 2026-07-13

### Added

- Windows PowerShell 5.1 daily production runner，提供 fail-fast、staging、no-overwrite、artifact tracking、UTF-8 log 與 JSONL trace。
- Scoring／ranking、watchlist／SMA200 audit、Dashboard、Social Card、Table Card、Cover／SEO overlay 的 end-to-end production sequencing。
- Runtime contract／schema enforcement、production path guard 與 shared sector presentation mapping。
- Repository README、production runbook、release notes及跨 PC source-control attributes。

### Release boundary

- v1.0.0 不包含 Archive、tmp／regression fixtures、歷史正式 outputs、local-only logo variants、自動 Commit／Push 或 GitHub Release automation。
- v1.0.0 唯一包含的 production brand asset 是 clean production logo。
